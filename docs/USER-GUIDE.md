# YI M1 遥控 · 使用指南

一款第三方 Android 应用，用来在官方 App「小蚁微单相机 / YI Mirrorless」服务器关闭后继续使用
**小蚁 YI M1 微单相机**：连接相机、实时取景、遥控拍摄、改相机参数、浏览/下载/删除相机内照片。

> 本应用为第三方开源项目，与小米/小蚁（Xiaoyi）官方无关。它通过逆向官方 App 得到相机**本地**
> 接口（相机自己发出的 Wi-Fi 热点 + BLE），不依赖任何已关闭的官方服务器。

---

## 一、准备

| 项目 | 要求 |
|---|---|
| 手机 | Android 8.0（API 26）及以上；需要 Wi-Fi 与蓝牙 |
| 相机 | YI M1（小蚁微单），已装好电池、插入 SD 卡并开机 |
| 安装 | 安装本项目提供的 `app-release.apk`（或 `app-debug.apk`） |

可以在手机文件管理器中点开 APK 安装；如提示「未知来源」，按系统提示允许安装。

## 二、第一次连接（重要）

相机的 Wi-Fi 默认是**关闭**的，热点密码**每次开机随机**，只有通过蓝牙才能拿到。App 里有两条路：

### 方式 A：蓝牙自动配网（推荐）

1. 打开 App → 底部「连接」。
2. 在「蓝牙自动配网」卡片点「扫描相机」。首次使用会请求蓝牙/附近设备权限，请允许
   （Android 12 以下还需要定位权限，且系统定位开关要打开）。
3. 相机开机、放在手机旁边；列表里出现相机后点它。
4. **看相机屏幕**：相机会弹出配对确认，请在相机上选择确认（几秒内完成）。
5. 成功后卡片会显示本次热点的 **SSID** 和**密码**（可复制），并且已经让相机打开了 Wi-Fi。
6. 点「打开 Wi-Fi 设置」，在系统 Wi-Fi 列表里连接那个 `YI_M1_…` 热点，输入刚显示的密码。
7. 返回 App →「连接」页 →「连接相机」。看到电量、剩余张数即连接成功。

> 注意：相机只能记住**一个**蓝牙配对。用本 App 配对后，官方 App 的配对会失效（反正也用不了了）；
> 反之，若相机仍绑定着别的设备，配对可能被拒绝，需要在相机菜单里解除旧绑定/恢复蓝牙设置后重试。

### 方式 B：手动连接（已经知道热点密码时）

1. 在相机屏幕上打开 Wi-Fi（相机菜单 → 连接设置；或按相机上的 Wi-Fi 键，视固件而定）。
2. 手机系统 Wi-Fi 里连接相机热点（密码见相机屏幕/此前保存的记录）。
3. 打开 App →「连接」→「连接相机」。
4. 若相机 IP 不是默认的 `192.168.0.10`，点右上角「关于/设置」→「相机地址」修改。

连接失败时先看页面底部的「连接帮助」：确认相机开机、插了 SD 卡、没有正在拍照、没有插 HDMI，
并确认手机的移动数据不会把请求抢走（App 会把网络绑定到相机热点；仍失败时可尝试关闭再打开 Wi-Fi）。

## 三、界面说明

### 连接
显示相机状态（电量、剩余张数、固件、镜头）、蓝牙自动配网、相机地址、连接帮助。
「外接电源」表示相机接了外部供电（相机用 101 表示充电中）。

### 遥控
* **实时取景**：连接后自动开始，约 1–2 秒延迟属正常；相机录像时会降到约 7.5 fps。
* **点击取景画面**：对焦到该点（出现对焦框）。
* **快门大按钮**：拍照；长曝光/连拍时可点取消。
* **自动对焦**：让相机对画面中心自动对焦。
* **底部参数条**：曝光模式（自动/P/A/S/M/C）、快门、ISO、光圈、EV、白平衡、对焦模式、驱动模式，
  点开选择即可；不适用的项会自动置灰。
* **拍摄设置**：画质、画幅比例、文件格式、色彩模式、测光、对焦、延时张数、手动对焦微调等。
* 相机改参数需要 1 帧左右才在 App 上回显，请以相机屏幕/下一帧状态为准。

### 相册
相机 SD 卡内容，最新在前，每页 60 张，滑到底自动加载。
* 点缩略图：全屏预览（先小图后清晰图）、下载、删除。
* **RAW 文件也有快速缩略图和预览图**（相机内置 JPEG 预览，约 0.3 秒/张），不再显示占位图。
* 预览页可双指缩放/拖动，并显示完整**照片信息**（尺寸、文件大小、光圈、快门、ISO、对焦模式、白平衡、焦距、厂商、机型、拍摄时间）。
* 拍摄时间按相机时钟显示（已按 UTC 修正，与拍摄时刻一致）。
* 长按：多选 → 批量下载 / 批量删除。
* 受保护（写保护）的文件不能删除，App 会自动跳过。
* 下载保存到系统相册的 `Pictures/YI M1 Remote/`。

### 本机
已下载到手机的照片/视频列表（来源：`Pictures/YI M1 Remote/`）。
* 点开：大图查看（双指缩放）、分享（系统分享面板）、向左/向右旋转并保存、删除本机副本。
* 长按：多选分享 / 删除。
* 注意：旋转会以较高压缩质量重新保存，20MP 照片在当前内存限制下可能被适度缩小；视频用系统播放器打开。

### 相机时间校准（连接页）
相机没有内置时钟，断电后会丢失时间。App 在连接成功后会尝试通过蓝牙自动对时，也可在「相机时间校准」卡片点击「对时」。需要先在「蓝牙自动配网」中成功连接过一次相机。

## 四、常见问题

| 现象 | 处理 |
|---|---|
| 扫描不到相机蓝牙 | 确认相机开机；手机蓝牙已开；已授予附近设备/定位权限；靠近相机重试；相机可能仍绑定别的手机 |
| 配对被拒绝 / 无确认弹窗 | 相机上确认弹窗是否被忽略；在相机菜单解除旧绑定后重启相机再试 |
| 一直「连接中」 | 手机是否已连上相机热点；是否还连着别的 Wi-Fi/移动数据；关掉 VPN；重启相机 Wi-Fi |
| 取景黑屏/不动 | 返回连接页重连；相册页占用相机时先退出预览；相机正在拍长曝光时取景会暂停 |
| 相册加载失败 | 相机 SD 卡是否正常；重新插拔 SD 卡；重启相机 |
| 下载中断 | 相机热点信号弱/手机省电；靠近相机保持亮屏重试（不支持断点续传） |
| 照片时间不对 | 相机没有 RTC，时间取自 SD 卡/上次设置；打开 App 时会通过蓝牙对时（需先配对） |

## 五、已知限制

* **不支持视频录制**（官方 App 也没有；相机固件虽有录像命令但参数语义未经真机验证）。
* **不含**：摄影学院、大师随行、账号登录/云服务、社区/分享、固件升级、意见反馈（前者已随服务器关闭而失效，
  后两者出于安全与合规原因移除）。
* **不提供固件升级**：官方固件下载源已关闭，刷错固件有变砖风险，App 只显示版本号。
* 相机热点没有互联网、且只允许**一台**设备连接；同一时间不要用另一台手机/电脑连同一台相机。
* 相机本地接口**没有鉴权**，同热点下任何人都能控制相机，请在可信环境使用。
* 蓝牙配网、BLE 对时、RAW 缩略图、照片信息、本机相册等功能均已在实体相机上联调通过；
  如遇问题请按上面的「常见问题」处理，并在反馈中附上连接页的诊断信息。
* 已在 Android 16 手机（Android 16）+ 小蚁 YI M1 上完成真机联调；其他品牌/系统版本仍需自行验证。

## 取景辅助、曝光检查、间隔拍摄与 BKT（v1.0.4）

### 取景辅助
在「遥控」页取景画面右上角点 **辅助设置**（圆形图标），可开关：

* **峰值对焦**：画面中清晰边缘显示彩色描边，用于手动对焦；
* **高光斑马纹**：过曝区域用洋红色条纹标出；
* **九宫格**：三分线构图参考；
* **水平仪**：显示手机横滚角（°），水平时变绿；
* **直方图**：实时亮度分布；
* **曝光模拟（客户端）**：按当前 EV 做屏幕亮度模拟，仅供构图参考，**不是相机真实曝光预览**。

### 曝光检查（M 档试拍）
M 档取景亮度不随曝光变化（相机固件限制）。点取景下方的 **曝光检查**：App 会拍一张试拍照片，
下载其预览并计算平均亮度、高光溢出、暗部溢出，给出偏暗/偏亮/合适建议；可点 **删除试拍** 清理。

### 间隔拍摄 / 曝光包围（BKT）
点 **间隔/BKT**：

* 间隔拍摄：设定张数（2–30）与间隔（1–60 秒），App 定时触发快门；
* 曝光包围：在间隔基础上按 0.3 / 0.7 / 1.0 EV 步长自动改变曝光补偿，拍完自动恢复原来的 EV。

> 3.1 固件不接受相机端的间隔/张数命令（HTTP 404），因此该功能由 App 端计时实现；请在拍摄期间
> 保持 App 在前台并保持相机连接，切后台会自动停止。

### 电量显示
相机用电池供电时，首页/遥控页显示 **电量百分比**（如 `50%`）；接 USB 供电/充电时显示
**外接电源（充电中）**（相机此时只上报 101，不提供百分比）。实测量值可能以较粗的档位变化
（25/50/75...）。

## 机身信息与对焦区域（v1.0.5）

### 机身/镜头/区域信息
「连接」页的相机状态卡新增：

* **固件版本**：机身固件（如 `3.1-cn`，来自相机蓝牙 `41106da2`）；
* **区域**：`M1CN`（中国版）或 `M1INT`（国际版）；
* **镜头固件**：镜头固件版本（如 `1.0`）；
* **读取机身信息**：只连接蓝牙读取该信息后立即断开，不重新配对、不改变 Wi-Fi；
  结果会保存，下次打开 App 直接显示。

### 对焦区域与对焦反馈
「遥控」页取景下方新增 **区域：点选 / 自动** 按钮：

* **点选**：点击画面任意位置，相机对该点进行单次自动对焦（`RCDoFocus Mode=Manual`）；
* **自动**：由相机选择对焦区域（`RCDoFocus Mode=Auto`），App 会显示相机返回的对焦点；
* 对焦时显示**橙色**对焦框；相机完成对焦后变**绿色**（约 2 秒后淡出）；失败显示**红色**并提示原因；
* 右上角「自动对焦」按钮同样会触发自动区域对焦。
